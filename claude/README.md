# SEOmatic for Claude

SEOmatic is the SEO agent for your own website. This plugin connects Claude
Code and Cowork to SEOmatic's hosted MCP server and adds SEO skills.

- **MCP server:** `https://app.seomatic.ai/api/mcp` (Streamable HTTP). Sign in
  with your SEOmatic account through OAuth when Claude first connects. No key
  goes in this plugin.
- **Skills:** site audit, striking-distance keywords, traffic-drop diagnosis,
  AI visibility and citations, keyword and backlink research, content briefs
  and refreshes, internal linking, indexing checks, local SEO, weekly briefs,
  client reports and the approval workflow, plus a skill for the SEOmatic CLI.

## What it can do on your site

Reading your own data (Search Console, audits, stored results) is free. Live
market data, fresh AI visibility scans and approved fixes use SEOmatic credits;
each tool says so before it runs. Fixes Claude stages wait for your approval
in SEOmatic. SEOmatic's own agent, in its default mode, also ships small,
undoable fixes by itself. Every change can be rolled back.
