# Routine: Weekly SEO review

**Schedule:** every Monday, 09:00 (user's timezone)

**Prompt:**

Run my weekly SEO review using SEOmatic:
1. Pull last week's Search Console performance and compare to the prior week.
2. List keywords now in striking distance (positions 8-20 with real
   impressions) that were not there last week.
3. Flag any page whose clicks dropped more than 20% week over week.
4. End with ONE recommended action for this week, with the reasoning.
If nothing changed materially, say so in one line and stop.
